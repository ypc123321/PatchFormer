## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 某实验报 `CUDA out of memory` | 显存被其它程序占用 | 关掉浏览器硬件加速/其它 GPU 程序；或 `--batch_size 64` |
| 表 3 某些单元格是 `—` | 该实验没有结果文件 | 看 `logs/<模型>_<电池>.log` 末尾，续跑 |
| 论文里出现“[缺失图片: xxx.png]” | 图片不存在 | 先跑 `tools/make_figures.py`，再在 Word 中更新图片 |
| `verify_reproduction.py` 报 CSV 缺失 | 没先汇总指标 | 先跑 `tools/collect_metrics.py` |
| 无 GPU 时训练很慢 | 已回退 CPU | 属正常现象；建议至少 16 GB 内存 |
| 公式显示成方框 | 缺 Cambria Math 字体 | Word 内选中公式 → 字体改为 Cambria Math |
